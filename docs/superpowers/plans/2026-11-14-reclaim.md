# Reclaimed Shading Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A thick blob of pixels inside a labelled component, far from the label's colour, gets a palette entry of its own after Rescue.

**Architecture:** One new pass `region.Reclaim` in `internal/region/reclaim.go`, called from `segmentColour` directly after `region.Rescue` under the same no-fixed-palette guard. It reuses `meanLab`, `coherent`, `compact` and Rescue's candidate ordering.

**Tech Stack:** Go 1.26, no new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-14-reclaim-design.md`

## Global Constraints

- `CGO_ENABLED=0`, only `golang.org/x/image`.
- Pixel and polygon goldens byte-identical unless the bench file justifies a change; refined goldens by quality compare.
- Gate before push: `make lint test wasm-check wasm wasm-test web-test` and `GOARCH=amd64 go test ./ ./internal/gradient/`.
- Constants: `reclaimMinArea` 64, `reclaimInterior` 0.5, `reclaimCoherence` 0.5, `reclaimMax` 32.

## Review Focus

- A blob touching the image border: border pixels have fewer than four neighbours and count as non-interior; a band along the border still qualifies when its inner rows do. Pinned by `TestReclaimBlobAtBorder` in Task 1.
- Two blobs of the same new colour in one image: the second shares the entry the first added. Pinned by `TestReclaimSharesAddedEntry` in Task 1.
- Labels at 255 with a full palette: no append past 256. Pinned by `TestReclaimCapsEntries` in Task 1.
- A blob whose label is a Rescue entry just added: Reclaim runs after compaction, so indices are current. Covered by the segment test in Task 2.
- Transparent pixels: `rgb` is flattened on white before segmentation, as for Rescue; nothing new.

### Task 1: `region.Reclaim`

**Files:**
- Create: `internal/region/reclaim.go`
- Test: `internal/region/reclaim_test.go`

**Interfaces:**
- Consumes: `meanLab(rgb []uint8, pixels []int32) colour.OKLab`, `coherent(rgb, pixels, m, tol) bool` (its share is `rescueCoherence`; Task 1 adds a `share` parameter and keeps Rescue's call at `rescueCoherence`), `compact(labels, palette)`.
- Produces: `func Reclaim(labels, rgb []uint8, w, h int, palette []colour.OKLab, tol float64) []colour.OKLab`.

- [ ] **Step 1: Write the failing tests**

Helpers: `field(w, h, c colour.OKLab) (rgb []uint8)` painting a flat colour (via `ToSRGB8`), `paint(rgb, w, rect, c)`, and a lab-space `shift(c, dL)` returning `c` with `L + dL`. tol 0.04 throughout; `A = {0.86, 0.045, 0.075}`, `B = shift(A, -0.10)`.

```go
func TestReclaimBlobInsideComponent(t *testing.T)   // 64×64 A, 20×12 B at (20,20); labels all 0; palette {A} → patch labelled 1, len(palette)==2, Dist(palette[1], B) < 0.005
func TestReclaimTakesExistingEntry(t *testing.T)    // palette {A, shift(B, 0.02)}: patch labelled 1, len(palette)==2
func TestReclaimIgnoresStrand(t *testing.T)         // B painted 2×200 along y=30: labels unchanged, palette {A}
func TestReclaimIgnoresRamp(t *testing.T)           // 20×12 patch, L from A.L down to A.L-0.24 linearly across x: unchanged
func TestReclaimIgnoresSmall(t *testing.T)          // 8×6 patch of B: unchanged
func TestReclaimBlobAtBorder(t *testing.T)          // 64×20 band of B along the top edge: reclaimed
func TestReclaimSharesAddedEntry(t *testing.T)      // two 20×12 patches of B: both labelled 1, len(palette)==2
func TestReclaimCapsEntries(t *testing.T)           // 256×256, 40 patches 12×12 of distinct hues all far: len(palette) <= 1+32
```

- [ ] **Step 2: Run them to see them fail**

Run: `go test ./internal/region/ -run TestReclaim`
Expected: FAIL, `undefined: Reclaim`.

- [ ] **Step 3: Implement `Reclaim` in `internal/region/reclaim.go`**

Doc comment as the spec's Design section. Body: far mask; flood fill (explicit stack, 4-neighbours, same label and far) collecting `[]int32` pixels per blob; skip under `reclaimMinArea`; interior count with a per-blob membership check (a `[]int32` blob id per pixel, −1 outside); skip under `reclaimInterior`; `m := meanLab`; skip unless `coherent(rgb, pix, m, tol, reclaimCoherence)`; nearest existing entry within tol → relabel; else candidate; sort by gain; add as Rescue does with `reclaimMax`; `compact`.

Change `coherent`'s signature to take the share; update Rescue's call.

- [ ] **Step 4: Run the tests**

Run: `go test ./internal/region/`
Expected: PASS, all region tests.

```bash

git commit -s -m "region: Reclaim gives a thick far blob inside a component its own colour"
```
